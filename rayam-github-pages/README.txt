RAYAM GitHub Pages deployment

1. Create a GitHub repository, e.g. rayam.
2. Upload index.html and .nojekyll to the repository root.
3. Go to Settings -> Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and / (root), then Save.
6. GitHub Pages will publish the site at:
   https://YOUR-USERNAME.github.io/rayam/

The main entry file must remain named index.html.
